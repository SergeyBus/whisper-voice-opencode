# Changelog

## 1.0.1

- Очистка зависшего процесса записи переведена на точечную: определяется
  держатель временного WAV-файла (`lsof -t`) и завершается только его PID.
  Подбор процессов по шаблону имени больше не используется.
- Хелпер `shouldUseStaleRecorderGuard` (переименован).

## 1.0.0

Первый публичный релиз форка `whisper-voice-opencode`.

- Голосовой ввод (STT) для OpenCode через локальный `whisper.cpp`.
- Нормализация текста: облако (OpenCode Zen) или локально (Ollama / LM Studio),
  либо отключена (сырой текст whisper).
- Промпт нормализации сохраняет язык ввода (русский не переводится в английский).
- Поддержка macOS и Windows.
- TTS удалён.
